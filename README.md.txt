# LEN MODA - Catálogo Online

Catálogo web minimalista premium inspirado en Zara, Massimo Dutti y Uniqlo.  
Funciona como catálogo online conectado a WhatsApp, sin carrito ni pagos.

## 🚀 Características
- Mobile First y responsive.
- Carga automática desde Google Sheets (CSV).
- Secciones: Hero, Destacados, Nuevos ingresos, Catálogo completo.
- Filtros: Todos, Mujer, Hombre, Categorías.
- Botón WhatsApp en cada producto.

## 📂 Archivos
- `index.html` → estructura principal.
- `styles.css` → estilos minimalistas.
- `script.js` → lógica para cargar productos desde Google Sheets.

## 📦 Deploy en Vercel
1. Crear un repo en GitHub con estos archivos.
2. Conectar el repo a [Vercel](https://vercel.com).
3. Deploy automático → listo para compartir.
